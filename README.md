# طقس بلاد الشام - النسخة الثانية

## التشغيل (Python 3.10 أو أحدث)
```
pip install -r requirements.txt
uvicorn main:app --reload
```
- الصفحة الرئيسية: http://127.0.0.1:8000
- الخريطة: http://127.0.0.1:8000/map

## الملفات
- `main.py`    الخادم والمسارات وجلب البيانات والكاش
- `alerts.py`  محرك التنبيهات (العتبات في أعلى كل دالة، عدّلها بعد المعايرة)
- `push.py`    الإشعارات: الاشتراكات، منع التكرار، ساعات الهدوء
- `accuracy.py` قياس الدقة: قراءات METAR الحقيقية ومقارنتها بالتوقعات المسجلة
- `static/`    الواجهة (`index.html`، `map.html`)، وخدمة الإشعارات `sw.js`، والشعار

## كيف تعمل التنبيهات
- ستة أخطار: أمطار/سيول، ثلج، عواصف رعدية، رياح، صقيع، حر.
- ثلاثة مستويات: أصفر (انتبه)، برتقالي (استعد)، أحمر (خطر).
- المستوى يُعتمد عندما يتفق عليه نموذجان من ثلاثة على الأقل، وتظهر عبارة "اتفاق 2 من 3 نماذج".
- مناطق جافة (معان، العقبة، البحر الميت) عتبات السيول فيها أخفض.

## الإشعارات
- مفاتيح VAPID تُولَّد تلقائياً في `vapid_private.pem` أول تشغيل. لا ترفعها إلى GitHub ولا تفقدها،
  وإن فُقدت يحتاج كل المشتركين إلى إعادة الاشتراك.
- ضع بريدك في `VAPID_SUBJECT` (مثل `mailto:you@example.com`) قبل الإطلاق.
- على الإنترنت يلزم HTTPS. أما على جهازك فيعمل على localhost.
- على iPhone: الإشعارات تعمل بعد "إضافة إلى الشاشة الرئيسية".
- الخادم يفحص المشتركين كل 30 دقيقة. حد أقصى 3 إشعارات يومياً للجهاز، وساعات الهدوء 23:00-06:00
  (التنبيه الأحمر يتجاوزها).

## صفحات المدن والمحتوى
- `/weather/amman` وما يماثلها: صفحة لكل مدينة تُرسم على الخادم (عنوان ووصف وOpen Graph وcanonical)، وفيها ملخص اليوم ونصائح اللباس والخروج وجدول 7 أيام وروابط لباقي المدن.
- `/sitemap.xml` و`/robots.txt` تُولَّد تلقائياً. بعد النشر ضع عنوان موقعك: `SITE_URL=https://موقعك` ثم قدّم `sitemap.xml` في Google Search Console.
- بطاقة المشاركة تُرسم في المتصفح (صورة 1080×1350) وتُشارَك مباشرة على الهاتف أو تُنزَّل على الحاسوب.
- ملخص اليوم والنصائح قواعد ثابتة في `content.py` تصوغ التوقع بالعربية، وليست تحليلاً بشرياً. راجع صياغتها وعدّلها كما تريد.
- صورة المعاينة عند مشاركة الرابط هي الشعار؛ لصور معاينة خاصة بكل مدينة يلزم توليد صور على الخادم.

## قياس الدقة
- كل 6 ساعات يسجّل الخادم توقعات كل المدن ويجلب قراءات مطارات حقيقية (METAR) من aviationweather.gov.
- يقارن العظمى والصغرى وحدوث المطر بالتوقعات التي صدرت قبل 1 و2 و3 أيام.
- يظهر الناتج في بطاقة «دقة توقعاتنا» بالصفحة الرئيسية وفي لوحة `/accuracy`. لا يظهر رقم قبل 3 أيام مكتملة.
- المحطات المرشّحة في `STATIONS` بملف `accuracy.py`. تحقق منها قبل الاعتماد عليها:
```
python accuracy.py --check      # أي المحطات ترد فعلاً
python accuracy.py --discover   # محطات METAR القريبة من كل مدينة
python accuracy.py --collect    # جلب القراءات الآن
python accuracy.py --stats      # الإحصاءات الحالية
```
- ليست لكل مدينة محطة. وهي مطارات، فقد تختلف حرارتها عن قلب المدينة، وMETAR لا يعطي كمية المطر.
- على ويندوز ثبّت `tzdata` (موجودة في requirements.txt) ليُحسب اليوم المحلي بدقة.

## قبل الإطلاق التجاري
- Open-Meteo المجانية لغير التجاري فقط: اشترك بخطة تجارية وضع المفتاح في `OPEN_METEO_API_KEY`.
- بلاطات OpenStreetMap للتجربة فقط، استخدم مزود بلاطات مناسباً عند ازدياد الزوار.
- طبقات الخريطة من النموذج وليست رادار حقيقي. للرادار راجع شروط RainViewer التجارية أو بدائله.
- اجعل تنبيهاتك تحت مراجعة بشرية في أول مواسم الشتاء، وقارنها بالتحذيرات الرسمية.
