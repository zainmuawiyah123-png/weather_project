# طقس بلاد الشام — نسخة جاهزة للإعلانات والتحقيق المالي
# Levant Weather — ad-ready, monetisation-ready build

منصة طقس عربية تغطي **25 مدينة** في الأردن وفلسطين ولبنان وسوريا، مع طبقة إعلانات
كاملة ولوحة تحكم مالية. هذه النسخة تُصلح ثغرة SSRF، وتُشغّل لوحة الدقة لكل المدن،
وتضيف محرّك إعلانات (حملات، جدولة، ظهور، نقرات، CTR، إيراد)، وصفحة «أعلن معنا»،
و`ads.txt`، واحترام الخصوصية، واختبارات آلية.

An Arabic-first weather platform covering **25 cities** across Jordan, Palestine,
Lebanon and Syria, with a full advertising layer and a revenue dashboard. This
build fixes the SSRF hole, makes the accuracy dashboard work for every city, and
adds an ads engine (campaigns, scheduling, impressions, clicks, CTR, revenue),
an "Advertise with us" page, `ads.txt`, privacy-respecting consent, and tests.

## 1) التشغيل السريع · Quick start

```bash
python -m venv .venv && source .venv/bin/activate   # اختياري / optional
pip install -r requirements.txt
cp .env.example .env        # ثم عدّل القيم / then edit values
uvicorn main:app --host 0.0.0.0 --port 8000
```

- الصفحة الرئيسية: <http://127.0.0.1:8000>
- الخريطة: <http://127.0.0.1:8000/map>
- لوحة الدقة: <http://127.0.0.1:8000/accuracy>
- أعلن معنا: <http://127.0.0.1:8000/advertise>
- لوحة الإعلانات: <http://127.0.0.1:8000/admin>

### متغيّرات البيئة المهمة · Key environment variables

| المتغيّر | الوصف |
|---|---|
| `DATA_DIR` | مجلد كل ما يُكتب (قواعد البيانات، مفاتيح VAPID، رمز اللوحة). الافتراضي `./data`. **لا يُكتب أي ملف داخل مجلد الكود**، فيعمل التطبيق على نظام ملفات للقراءة فقط. |
| `SITE_URL` | رابط الموقع الكامل (sitemap، canonical، og:url). |
| `ADMIN_TOKEN` | رمز الدخول إلى `/admin`. إن تركته فارغاً يُولَّد رمز ويُطبع في سجل الخادم عند أول تشغيل. |
| `OPEN_METEO_API_KEY` | مفتاح Open-Meteo التجاري. اتركه فارغاً للتجربة (غير تجاري فقط). |
| `VAPID_SUBJECT` | بريد المسؤول في مطالبات VAPID. |
| `ADSENSE_CLIENT` | معرّف شبكة AdSense (اختياري؛ يمكن ضبطه من اللوحة). |
| `ADS_BEFORE_CONSENT` | `0` (افتراضي) = لا يُحمَّل أي إعلان قبل موافقة الزائر. |

> **مهم:** كل ما يُكتب يذهب إلى `DATA_DIR`. على منصات مثل Heroku/Render/Fly اضبط
> `DATA_DIR` على قرص دائم، وإلا فُقدت قاعدة البيانات عند كل إعادة نشر.

## 2) لوحة الإعلانات · The ads dashboard

افتح `/admin` وأدخل `ADMIN_TOKEN`. اللوحة محمية بجلسة موقّعة (HMAC) في كوكي
`HttpOnly`، وتحديد معدل على مساراتها.

**ما تجده في اللوحة:**

- **الإجماليات:** الظهور، النقرات، نسبة النقر (CTR)، الإيراد بالدينار الأردني.
- **الحملات:** جدول بكل حملة مع ظهورها ونقراتها وCTR وإيرادها، وأزرار تشغيل/إيقاف.
- **إضافة حملة:** الاسم، المعلن، المكان، الصيغة، نموذج التسعير (CPM/CPC/ثابت)،
  السعر، الميزانية، الحد اليومي، **تاريخ البداية والنهاية**، الأولوية، رابط الوجهة.
- **إضافة إبداع:** صورة (رابط) أو نص (عنوان/وصف/زر)، مربوط بحملة.
- **المعلنون:** سجل الجهات المعلنة.
- **طلبات الإعلان:** كل من أرسل نموذج «أعلن معنا».
- **إعدادات الشبكة:** معرّف AdSense وأسطر `ads.txt` إضافية.
- **تصدير:** زر «تصدير تقرير 30 يوماً (CSV)» → `/admin/report.csv?days=30`.

### كيف يُحسب الإيراد · How revenue is computed

- **CPM:** `الظهور ÷ 1000 × السعر`
- **CPC:** `النقرات × السعر`
- **ثابت (flat):** السعر كما هو (للرعاية الموسمية)

### التوزيع والعدالة · Serving & fairness

عند كل طلب إعلان يختار المحرّك الحملات **النشطة والمجدولة** للمكان، ويستبعد ما بلغ
حدّه اليومي، ثم يوزّع بالتناوب على الأقل ظهوراً اليوم (عدالة بين المعلنين). إن لم
توجد حملة، يظهر **إعلان البيت** («أعلن معنا») بدل فراغ.

## 3) ربط شبكة إعلانات حقيقية · Connecting a real ad network

المنصة تعمل بنموذجين معاً: **بيع مباشر (Direct)** عبر اللوحة، و**شبكة إعلانات**
(AdSense أو ما يعادلها) عبر كود يُضاف في الأماكن.

**الخطوات:**

1. أنشئ حساباً في شبكة الإعلانات (مثلاً Google AdSense) وأضف موقعك وانتظر الموافقة.
2. خُذ معرّف الناشر (مثل `ca-pub-0000000000000000`).
3. في اللوحة → **إعدادات الشبكة الإعلانية** → الصق المعرّف → احفظ.
4. تحقّق من `/ads.txt` — يجب أن يظهر سطر:
   `google.com, pub-0000000000000000, DIRECT, f08c47fec0942fa0`
5. أضف أسطراً إضافية (مزودون آخرون) في نفس الصفحة، سطر لكل جهة.
6. لتفعيل كود الشبكة في الصفحات: أضف وسم `<script>` الخاص بالشبكة في
   `static/index.html` و`static/map.html` و`pages.py` (دالة `_head`)، داخل
   `ad-slot` المطلوب. الإعلانات المباشرة من اللوحة تعمل بلا أي كود إضافي.

**ملاحظات امتثال مهمة:**

- **لا تُحمَّل الإعلانات قبل موافقة الزائر** (`ADS_BEFORE_CONSENT=0`). شريط
  الموافقة في `static/ads.js`، وسياسة الخصوصية في `/privacy` تشرح ذلك.
- كل إعلان موسوم بكلمة **«إعلان»** و`rel="nofollow sponsored"`.
- لا تُخزَّن أي بيانات بطاقة على الخادم (لا يوجد دفع في هذه النسخة).
- `ads.txt` يُدار من اللوحة؛ لا تعدّله يدوياً إن كنت تستخدمها.

## 4) الإصلاحات في هذه النسخة · What was fixed

| # | المشكلة | الإصلاح |
|---|---|---|
| 1 | **ثغرة SSRF:** كان الخادم يقبل أي رابط اشتراك ثم يرسل إليه طلباً (يمكن مسح الشبكة الداخلية و`169.254.169.254`). | `security.validate_push_endpoint`: قائمة نطاقات خدمات الإشعارات فقط، رفض العناوين الداخلية/المحلية/الوصفية، HTTPS فقط، منفذ 443 فقط، ومنع بيانات الدخول في الرابط. |
| 2 | **ربط الاشتراك بمن طلبه:** أي أحد يستطيع إلغاء/اختبار اشتراك غيره. | كل اشتراك يحصل على **رمز مالك** عشوائي؛ الإلغاء والاختبار يتطلبان الرمز. |
| 3 | **خطأ 500** عند مفاتيح اشتراك تالفة في اختبار الإشعارات. | `push.send_push` يلتقط `binascii.Error` و`ValueError` و`TypeError` وأي خطأ شبكة، ويعيد `False` بدل الانهيار. |
| 4 | **لوحة الدقة فارغة لـ23 مدينة** (محطات لا ترد). | مصدران: **Ogimet METAR** (يغطي المحطات الأردنية/السورية/اللبنانية) + **أرشيف توقعات Open-Meteo** لتعبئة السجل فوراً. لكل مدينة قائمة محطات مرشّحة، وبديل **إقليمي واضح** عند غياب الرصد. |
| 5 | **JSON خام** يظهر للمستخدم عند فشل مصدر البيانات. | معالجات أخطاء تُعيد **صفحة خطأ عربية منسّقة** (`pages.render_error`) لطلبات HTML، وJSON للمسارات. |
| 6 | **الخريطة فارغة بلا رسالة** عند فشل الجلب. | `/api/overview` يعيد 502 برسالة عربية بدل قائمة فارغة، و`/api/grid` يعيد نسخة قديمة أو خطأ واضح. |
| 7 | **لا حدود للطلب ولا للحقول ولا تحديد معدل.** | حد حجم الطلب (64KB)، حدود طول لكل حقل (Pydantic)، وتحديد معدل لكل IP على كل مجموعة مسارات. |
| 8 | **لا `.gitignore`** مع تحذير عن `vapid_private.pem`. | `.gitignore` يستثني `data/` و`*.db` و`vapid_private.pem` و`.env`. |
| 9 | **كتابة ملفات عند الاستيراد** (تفشل على نظام للقراءة فقط). | كل الكتابة في `DATA_DIR`، وقواعد البيانات تُنشأ عند أول استخدام فعلي. |
| 10 | **مكتبات غير مثبّتة.** | `requirements.txt` بإصدارات مثبّتة. |
| 11 | **لا اختبارات.** | `tests/test_core.py`: **45 اختباراً** للتنبيهات والدقة والمسارات والإعلانات والأمان. |

## 8) قبل الإطلاق التجاري · Before going commercial

- **Open-Meteo المجانية للاستخدام غير التجاري فقط.** اشترك بخطة تجارية وضع
  المفتاح في `OPEN_METEO_API_KEY`.
- **بلاطات OpenStreetMap للتجربة فقط.** استخدم مزوّد بلاطات مناسباً عند ازدياد الزوار.
- **طبقات الخريطة من النموذج وليست راداراً حقيقياً.**
- **التنبيهات آلية وتقديرية** — اجعلها تحت مراجعة بشرية في أول موسم شتاء، وقارنها
  بالتحذيرات الرسمية من دوائر الأرصاد والدفاع المدني.
- **اضبط `ADMIN_TOKEN`** في الإنتاج (لا تتركه مولَّداً في السجل).
- **اضبط `DATA_DIR`** على قرص دائم.
